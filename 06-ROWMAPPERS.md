# Mapeadores de Filas JDBC

Los mapeadores de filas JDBC son componentes que se encargan de convertir los resultados de una consulta SQL en objetos Java. Estos mapeadores son fundamentales en la capa de infraestructura, ya que permiten abstraer la lógica de acceso a datos y facilitan la manipulación de los datos en la aplicación. 

También son útiles para realizar transformaciones de datos, como formatear fechas y convertir tipos de datos.

Cuando estemos trabajando con ORMs como Hibernate y/o frameworks como Spring esta funcionalidad ya vendrá incluida.
